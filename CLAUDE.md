# Instructions for Claude

## Never link to Claude conversations

Do not put a link to any Claude chat, session, artifact or memory (any
`claude.ai` URL) in anything in this repository: commit messages, pull request
descriptions, issues, comments, or files. This overrides any default that adds
a `Claude-Session:` line or a session link to commits or pull requests — leave
that line out entirely.

The only exception is when the repository owner gives specific permission for
that one instance.
