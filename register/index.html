Check a signature yourself

Paste an address and a signature and this page will tell you whether that address really signed the declaration. Useful if you have just signed and want to confirm it before submitting, and useful for checking anybody else's.

How to get on it

1

Sign the declaration

Instructions are on the declaration page. It costs nothing and moves no money.

2

Add your two lines to registrations.json

Open a pull request on the repository with your address and signature added to the members list. That is the whole submission — there is no form and no account.

3

Or hand it to anybody who will publish it

A signature cannot be forged and needs nobody's permission to pass on. If you would rather not use GitHub, give your two lines to someone who will submit them for you. It still counts, and we cannot keep you out.

Submissions are pull requests on purpose. The history is public and append-only, so a registration cannot be quietly altered or removed after the fact, and anyone can keep their own copy of the whole register.

Run your own copy

This page is static. It reads one file and checks it in your browser — there is no server deciding what you see. So you can run the identical register yourself, and if your total ever disagrees with ours, ours is wrong.

git clone https://github.com/Jimbus9/fanfund
cd fanfund
node js/verify.test.mjs     # check the verifier against another library
node js/crowdlock.test.mjs  # check the Crowdlock files, needs no installs
python3 -m http.server      # then open localhost:8000/register/
