Check it yourself

Nobody has to believe this page.

  1. Download the raw list — every member address, every signature, every lock.
  2. Check any signature against the declaration. It proves that address agreed to those exact words.
  3. Look up any lock on any block explorer. The coins and the date are on the blockchain, not in a database of ours.
  4. Add them up with the counting rule. If your number differs from ours, ours is wrong.

Anyone can run a copy of this register. Two honest copies always reach the same total, so a dishonest one is visible immediately.
